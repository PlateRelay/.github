# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities—especially issues involving physical printer control, daemon authentication or credentials, or `.gcode.3mf` validation bypasses.

Instead, please report vulnerabilities privately through GitHub Security Advisories:

- [Report a vulnerability](https://github.com/PlateRelay/PlateRelay/security/advisories/new)

When submitting a report, please include:

- Affected component or repository (e.g., panel server, web UI, or LAN daemon)
- Steps to reproduce or a minimal proof of concept
- Potential impact and any suggested mitigation

We will review reports as soon as possible and coordinate a fix before public disclosure.
